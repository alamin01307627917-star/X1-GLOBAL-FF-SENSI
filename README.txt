X¹ – GLOBAL FF SENSI
Blue + Black Free Fire sensitivity starter generator.

Files:
- index.html: website
- logo.png: app logo
- manifest.webmanifest + sw.js: installable PWA support
- android-wrapper/: Capacitor Android wrapper starter (not a compiled APK)

Publish website:
Upload index.html, logo.png, manifest.webmanifest and sw.js to Netlify.

Install on Android:
Open the published site in Chrome > menu (⋮) > Install app / Add to Home screen.
This installs the website as a PWA, not as a standalone APK.

Build APK:
See android-wrapper/README-APK-BN.txt. Requires a computer with Node.js and Android Studio/Android SDK. The APK is not compiled in this package.

Device list includes popular models across 20+ brands. Enter any missing model manually.
Sensitivity values are suggested starting presets only, not guaranteed perfect settings. The app does not modify Free Fire or game files and is not affiliated with Garena.
